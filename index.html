📜 Rules Compass

CORE LOOP\nDescribe intent → DM decides whether a roll is needed → choose d20 test → roll d20 + relevant modifiers → compare to target → narrate consequence\n\nCOMBAT TURN\nMove ↔ Action ↔ Bonus Action (only if a feature grants one)\nReaction: triggered outside/inside your turn when its trigger occurs\nFree object interaction: limited/common interaction at DM adjudication\n\nSPELL CHECK\nCasting time → range → target/area → components → duration → concentration? → attack roll or saving throw? → effect\n\nDM RULING\nClarify intent → check applicable rule → judge uncertainty/stakes → set method/DC if needed → resolve → keep play moving → research later if necessary.

Rules labels: 📘 core rule • 🧩 optional/variant • 🕰️ legacy 2014 • 🔨 homebrew/training.
